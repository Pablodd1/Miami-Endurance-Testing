# Miami Endurance Testing

A modern, bilingual (English/Spanish) website for Miami Endurance Testing - scientific performance testing for endurance athletes.

## Features

- **Bilingual Support**: Toggle between English and Spanish
- **Neumorphism Design**: Modern soft UI with 3D card effects
- **Training Zone Education**: Detailed explanations of all 5 training zones
- **Interactive Calculator**: Calculate personalized heart rate zones
- **Mobile Responsive**: Works on all devices

## Services & Pricing

- **Lactate Threshold Test**: $150
- **VO2max Test**: $250 (Home or Office)
- **Resting Metabolic Rate (RMR)**: $250 (Home or Office)
- **Lactate + Sweat Combo**: $200
- **Personalized Coaching**: $300/month
